# ADR-010 — hidden-reference boundary between runtime and research evaluation (2026-10-15)
- Decision: hidden evaluation data is unavailable to the runtime. It consists of the original reference audio (clean/reference condition and any manual correction reference) and the defect-injection ground truth (defect type, target tracks, injection parameters, random seeds and labels derived from them). The runtime comprises every comparison condition's controller, the controllers' decision inputs, and runtime validation and verification. Hidden evaluation data is stored separately from runtime inputs and run records and is used only by post-run research evaluation. A combined research report may join run records with hidden evaluation data after execution has finished.
- Definitions: *run records* (FR-12) contain runtime-visible inputs and the ordinary action history of the run, i.e. measurements, candidates, proposals, validation results, executed corrections, verification outcomes, rollbacks and stop reasons. That history is runtime information and remains available to the run (FR-06). *Hidden evaluation data* is never part of it. Identifiers that link run records to hidden evaluation data must not encode injection details.
- Source: owner's instruction of 2026-10-15; previously listed as an open conflict in `agent-team/PROJECT_BRIEF.md` (ADR-009 consequences).
- Rationale: if a controller or the runtime validator could see the reference or the injected defect, it would have an oracle unavailable in real use. Results would be inflated and the comparison invalid (SR-01, SR-03). The Source of Truth document v0.1 proposes the same separation (sections 4.4, 7.4, 9.3).
- Consequences:
  - Requirements v1.1: new SR-10; FR-18, FR-12 and the system-context inputs and outputs are reworded accordingly.
  - Refines ADR-008's consequence that injection parameters and seeds are recorded per variant: they are recorded in the hidden evaluation data, not in runtime inputs or run records. ADR-008 otherwise remains in force.
  - Closes the "hidden reference" item that ADR-009 listed as open; ADR-009 otherwise remains in force.
  - Which other project metadata fields enter decision inputs is not decided here (FR-06, D6, D7).
